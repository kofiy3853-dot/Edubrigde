# EduBridge OS

Enterprise-grade education platform connecting students with universities worldwide.

## Project Structure

```text
EDUBRIDGE/

├── apps/                 # Frontend applications
├── backend/              # Backend services
├── packages/             # Shared libraries and utilities
├── database/             # Database schemas, migrations, seeds
├── infrastructure/       # Docker, CI/CD, deployment configs
├── documents/            # Architecture docs, API specs, guides
├── tests/                # End-to-end and integration tests
├── .github/              # GitHub Actions workflows
```

## Tech Stack

| Layer | Technology |
|-------|-----------|
| Frontend | Next.js, TypeScript |
| Backend | Spring Boot, Java |
| Database | PostgreSQL, Redis |
| Messaging | Apache Kafka |
| Storage | MinIO |
| Container | Docker |
| CI/CD | GitHub Actions |
| Monitoring | OpenTelemetry, Grafana, Prometheus |
| Security | OWASP, SonarQube |
| Testing | Playwright, Vitest, JUnit, Mockito |

## Getting Started
